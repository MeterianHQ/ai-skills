# tessl/

This directory contains tessl-specific versions of the skills for local development and publishing via the [Tessl](https://tessl.io) package manager.

## Why a separate folder

`skills/*/SKILL.md` is the single source of truth for all other agent integrations (Claude Code plugin, Windsurf, Copilot, etc.). The `tessl/` directory holds independent copies so tessl-specific improvements (metadata, LANGUAGES.md bundles, wording tuned to tessl's review rubric) can be iterated without touching the canonical skill files.

When changes here are stable, propagate them back to `skills/*/SKILL.md` and the other tool-specific files as appropriate.

## Structure

```
tessl/
  security-audit/
    SKILL.md        # tessl-optimised skill content
    LANGUAGES.md    # manifest-to-language mapping (referenced from SKILL.md)
    tile.json       # tessl tile manifest (generated by `tessl skill import`)
  reachability-analysis/
    SKILL.md
    tile.json
```

## Local dev workflow

```bash
# After editing a SKILL.md:
tessl tile pack ./tessl/security-audit
tessl install ./local-security-audit-0.1.0.tgz
# then /reload-plugins in Claude Code

# Review quality:
tessl skill review ./tessl/security-audit

# Lint only:
tessl skill lint ./tessl/security-audit
```

Use `--watch-local` to auto-reinstall on file changes:

```bash
tessl install --watch-local ./local-security-audit-0.1.0.tgz
```

## Versioning

Version is tracked in each `tile.json` (`metadata.version`), independently from the Claude Code plugin version in `.claude-plugin/plugin.json`.

## Publishing

```bash
tessl skill publish ./tessl/security-audit
```
